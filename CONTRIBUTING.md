# Contributing

Bu rehber gerçek kullanım deneyiminden doğdu. Katkılar memnuniyetle kabul edilir.

- Donanım ve işletim sistemi farklarını açıkça belirtin.
- Şifre, API key, gerçek Tailscale IP veya kişisel ekran görüntüsü göndermeyin.
- Troubleshooting katkılarında “belirti → test → bulgu → çözüm” formatını tercih edin.
- HEIC problemi için mümkünse File Browser sürümü, FFmpeg sürümü ve preview endpoint'in HTTP durumunu ekleyin.
- Büyük davranış değişikliklerini ayrı PR olarak gönderin.
