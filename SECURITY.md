# Security

## Public internet exposure

Bu rehberde servislerin doğrudan modem/router üzerinden internete açılması önerilmez. Uzak erişim için özel ağ yaklaşımı kullanılır.

NAStool arşivlenmiş bir projedir ve legacy yazılım olarak değerlendirilmelidir.

## Repoya eklenmemesi gerekenler

- `.env`
- File Browser veritabanı
- NAStool `/config`
- TMDB API anahtarları
- Tailscale auth key'leri
- Gerçek parolalar
- Gerçek özel ağ IP'leri
- Hesap bilgisi içeren ekran görüntüleri

## İlk giriş

Bir ürün varsayılan kimlik bilgileriyle başlıyorsa, uzak erişimi açmadan önce bunları değiştirin.

## Güvenlik bildirimi

Bu repodaki yardımcı scriptlerde güvenlik problemi bulursanız, gizli bilgi veya aktif kimlik bilgisi yayınlamadan issue açın.
