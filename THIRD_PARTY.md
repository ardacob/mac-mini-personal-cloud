# Third-party software

This repository is a setup guide and helper-script collection. It does not replace or relicense the projects it installs.

- **NAStool / nas-tools** — https://github.com/NAStool/nas-tools — AGPL-3.0, archived by the upstream project.
- **File Browser Quantum** — https://github.com/gtsteffaniak/filebrowser — see upstream repository for current license and terms.
- **Docker Desktop / Docker Engine** — https://www.docker.com/ — see Docker's terms and licensing.
- **Tailscale** — https://tailscale.com/ — see Tailscale's terms and licenses.
- **FFmpeg** — https://ffmpeg.org/ — licensing depends on build configuration.

The MIT license in this repository covers only the original documentation and helper scripts authored for this guide, except where a file states otherwise.
